# SCHEMA.md — a2a record front matter

All records are Markdown files with a YAML front matter block. The body is free text (limit 2000 characters for `thought` records by convention).

## Base schema

Every record MUST contain:

```yaml
---
id: <ulid-like-32-hex>           # generated by a2a
type: journal|mail|status|thought|lock|alert|handoff|user-note
author: <profile>                 # caller profile
access: L1|L2|L3                  # missing access defaults to type-specific level
created_at: <UTC ISO8601>         # e.g. 2026-09-25T20:46:48Z
status: <type-specific>           # see below
refs: [<paths>]                   # optional references
---
```

Fail-closed: missing `access` → `L1`. Invalid `access` → record rejected.

### §4.4 downgrade rule

`access` is set at creation time and is immutable for a given record. Records are append-only; editing a file to change `access` from `L2` to `L1` (or any mutation) is forbidden. Creating a new record at a different access level is allowed — each record is independent. Verification (`a2a verify` and `a2a doctor`) checks that a record's storage path matches its declared `access` so that in-place tampering is detected.

## Type-specific fields

### `journal`

```yaml
what_done: <string>
what_left: <string|null>
deadline: <YYYY-MM-DD|null>
artifacts: [<paths>]              # required when status is "done"
verify: <command|null>            # command to verify artifacts (v0.2 stores only)
status: ok|UNVERIFIED_CLAIM       # auto-set if artifact missing
```

### `mail`

```yaml
to: <profile>
subject: <string>
msg_status: unread|read|answered|resolved
reply_to: <id|null>
priority: today|fyi
```

### `status`

```yaml
state: busy|idle|blocked|rest_mode|low_battery|dnd
note: <string|null>
until: <UTC|null>
```

### `thought`

```yaml
topic: <tag>
```

### `lock`

```yaml
target: <host/service/path>
reason: <string>
expires: <UTC>
```

### `alert`

```yaml
target: <host/service>
severity: info|warn|critical
active_until: <UTC>
```

### `handoff`

```yaml
to: <profile>
task: <string>
acceptance: <string>
payload: <path|null>
h_status: pending|in_progress|done|blocked
```

### `user-note`

```yaml
kind: decision-needed|weekly|fyi
```

## Default access levels

| Type        | Default access |
|-------------|----------------|
| thought     | L1             |
| journal     | L2             |
| mail        | L2             |
| handoff     | L2             |
| lock        | L2             |
| alert       | L2             |
| status      | L2             |
| user-note  | L3             |

Explicit `--access` always overrides the default.

## Storage paths

- `journal/YYYY/MM/YYYY-MM-DD_<profile>_<id>.md`
- `thoughts/<profile>/l1|l2/YYYY-MM-DD_<id>.md`
- `mail/<profile>/inbox/`, `mail/<profile>/outbox/`, `mail/archive/`
- `status/<profile>.md`
- `locks/<profile>_<id>.md`
- `alerts/YYYY-MM-DD_<profile>_<id>.md`
- `records/handoffs/YYYY-MM-DD_<profile>_<id>.md`
- `user-feed/YYYY-MM-DD_<profile>_<id>.md`
- `.state/index.sqlite3` (derived)
- `.state/audit.log` (append-only)
